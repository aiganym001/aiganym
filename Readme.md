# Мен туралы

Менің атым – Айғаным. Мен 16 жастамын.
Политехникалық колледжде оқимын.
Менің мамандығым – бағдарламалық қамтамасыз етуді әзірлеу.

Мен ақпараттық технологиялар мен бағдарламалауға қызығамын.
Болашақта жақсы маман болып, өз жобаларымды жасағым келеді.

# Жоба туралы

Бұл жоба GitHub платформасымен жұмыс істеуді үйрену мақсатында жасалды.
Жоба барысында репозиторий құру, README.md файлын жасау,
Commit арқылы өзгерістерді сақтау және өзгерістер тарихын қарау әрекеттері орындалды.
